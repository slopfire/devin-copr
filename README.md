# Devin Desktop COPR

An RPM package for the x86_64 Devin Desktop. It repackages the official
upstream Linux tarball.

## COPR setup

1. Create a COPR project:

   ```bash
   copr-cli create \
     --chroot fedora-40-x86_64 \
     --chroot fedora-41-x86_64 \
     --chroot fedora-42-x86_64 \
     devin-desktop
   ```

2. In the GitHub repository, add these Actions secrets:

   - `COPR_CONFIG`: the complete `~/.config/copr` file generated by `copr-cli`.
     Keep it as a multi-line secret.
   - `COPR_PROJECT`: the COPR project identifier, for example
     `your-copr-user/devin-desktop`.

3. Enable Actions. The `Publish Devin Desktop to COPR` workflow checks the
   upstream API every 6 hours and submits a source RPM when it detects a new
   release. It records the successful submission in `packaging/last-built.json`.

Use **Run workflow** with `force` when a COPR rebuild of the same upstream
release is needed.

## Local build

On Fedora:

```bash
sudo dnf install rpm-build rpmdevtools curl jq
eval "$(scripts/update-check.sh)"
./scripts/build-srpm.sh "$version" "$timestamp" "$url" "$sha256"
```

The source RPM is written to `rpmbuild/SRPMS/`.
